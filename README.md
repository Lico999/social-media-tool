# Social Media Tool

Website prototype untuk menyiapkan konten media sosial dari satu halaman.

## Struktur proyek

- `index.html` — halaman utama website.
- `style.css` — tampilan dan desain website.
- `script.js` — interaksi tombol dan pemilihan platform.
- `assets/` — tempat file gambar, ikon, dan aset lain nanti.

## Status saat ini

Versi pertama adalah **prototype frontend**. Pengiriman postingan ke Instagram, Facebook, TikTok, atau YouTube belum aktif.

## Rencana pengembangan

1. Membuat dashboard yang lebih lengkap.
2. Menambahkan penyimpanan data.
3. Menambahkan sistem login.
4. Menentukan API resmi tiap platform.
5. Menambahkan koneksi platform satu per satu.
6. Menambahkan fitur posting dan penjadwalan setelah autentikasi/API tersedia.
